# RAPP Hive Hub join

**`main` keeps the previous design; this branch is the target shape.** On `main` this repository
is a set of per-app setup pages for an MCP server that downloads organization seed ZIPs. Here it
is the one line an AI app needs.

## The one line

Paste this into any AI app:

> Read https://raw.githubusercontent.com/kody-w/rapp-hive-hub-join/experimental/organism-fit/llms.txt,
> then help me find a Hive or a RAPP Work starter and join or start it with my own Brainstem.

## What the line gives the app

- **The RAPP hub's cards**, through its generated views:
  [`views/api/v2/index.json`](https://raw.githubusercontent.com/kody-w/rapp-hive-hub/experimental/organism-fit/views/api/v2/index.json)
  lists every card with its chant and sha256, and `views/api/v2/<kind>/<slug>.json` holds one
  card: Hive protocols, Hives, organizations (specified plans) and starters (experimental Hive
  templates under `starters/<slug>/`).
- **The join flow:**
  1. Dial a chant or open a card.
  2. Check the card's sha256 against the index.
  3. Give the card to your own Brainstem. Its Hive agent clones the Hive, verifies the root and
     the founder fingerprint, writes one SSH-signed request file, and sends it the way the card's
     channel says.
- **The start flow:** pull a starter's template down read-only (the Hive agent's `reference`,
  `npx degit` or a ZIP), and your Brainstem's Hive agent creates a new Hive from it, as the
  starter's README says.

There is nothing to install. The hub never writes into a Hive, keeps no subscription state and
runs nothing. Inside an MCP app, the optional read-only
[hive-hub-mcp](https://github.com/kody-w/hive-hub-mcp) server reads the same views as its
`rapp-hive-hub` hub.
